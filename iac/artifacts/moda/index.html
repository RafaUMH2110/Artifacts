GenPatModa

GenPatModa: versión para alumnos de GenPatMod. Genera patrones de corte de moda en SVG a partir de una idea y los exporta a PDF A4, usando Claude, OpenAI o Gemini, con el catálogo de modelos de Anthropic y el máximo de tokens limitados por el profesor.

GenImOda

GenImOda: versión de GenImOd para el aula. Genera imágenes de moda con Claude y FLUX, con la opción de omitir la mejora del prompt con Claude, y con modelos y parámetros limitados por el profesor.

Claude FLUX fal.ai Docencia Imágenes Moda

GenOutFitS

GenOutFitS: versión para alumnos de GenOutFit. A partir de la foto de una prenda, propone un outfit completo y genera cada pieza con fal.ai/FLUX; la foto final del modelo se compone con FLUX Kontext a partir de la prenda original y de las piezas ya generadas, para que las lleve puestas exactamente como se generaron, con el catálogo de modelos de Anthropic y los parámetros de FLUX limitados por el profesor.
