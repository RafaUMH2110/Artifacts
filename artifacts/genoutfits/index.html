¿Cómo funciona GenOutFitS?

GenOutFitS es la versión para alumnos de GenOutFit: una aplicación de un solo archivo HTML que, a partir de la fotografía de una prenda, usa IA para identificar sus características y proponer un outfit completo de prendas afines, y genera una imagen de cada pieza con FLUX (fal.ai).

Esta versión tiene algunos límites fijados por el profesor para controlar el coste y la complejidad: del proveedor Anthropic solo puedes elegir Claude Sonnet 4.5 o Claude Haiku 4.5, el máximo de tokens de salida es 8192, el outfit puede tener como máximo 3 piezas además de la prenda original, y los pasos de inferencia (10) y la tolerancia del filtro de seguridad (3) de FLUX están fijados y no son configurables.

  1. Subes (o arrastras) la foto de una prenda.
  2. Eliges cuántas piezas debe tener el outfit completo y si quieres además una imagen de un/a modelo vistiendo todo el conjunto.
  3. La IA (Claude, GPT o Gemini, a tu elección) analiza la foto y devuelve una descripción breve y un prompt en español, listo para FLUX, de cada pieza del outfit.
  4. Puedes revisar y editar cada prompt antes de continuar.
  5. Al pulsar "Continuar", GenOutFitS genera con FLUX una imagen PNG de cada pieza y, si la pediste, la foto del modelo: esta última se compone con FLUX Kontext a partir de la prenda original y de las imágenes de las piezas ya generadas, para que el modelo lleve exactamente esas prendas y complementos.
  6. Puedes descargar cada imagen por separado o exportarlas todas juntas en un PDF.

Avisos frecuentes: error 401/403 → la clave no es válida o no tiene permisos. Error 429 → límite de uso alcanzado, espera e inténtalo de nuevo. Error 404 → el modelo no existe o no está disponible en tu cuenta. "La respuesta no tiene el formato esperado" → GenOutFit reintenta automáticamente una vez; si persiste, prueba con otro modelo o una foto más clara de la prenda.

Cuántas prendas afines debe proponer la IA, además de la que has subido. Los pasos de inferencia (10) y la tolerancia del filtro de seguridad (3) de FLUX están fijados por el profesor en esta versión. El máximo de piezas es 3 para que, junto a la prenda original, nunca se superen las 4 imágenes de referencia que fal.ai admite por llamada: así la foto del modelo se genera siempre en una sola llamada, sin pasos intermedios que puedan perder fidelidad.

Esta foto no se genera solo a partir de texto: se compone con FLUX Kontext a partir de la prenda original y de las imágenes de cada pieza ya generadas, usándolas como referencia, para que el modelo lleve EXACTAMENTE esas prendas y complementos. Con el máximo de 3 piezas, la prenda original más las piezas nunca supera las 4 imágenes de referencia que admite fal.ai por llamada, así que se genera siempre en una sola llamada.

Rol que sigue la IA al analizar la prenda y redactar los prompts. Puedes editarlo; por defecto es el definido para esta app.
