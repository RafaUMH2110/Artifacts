GenOutFitFace

Sube la foto de una prenda y, si quieres, de una persona, y genera con IA un outfit completo a juego — con la foto del modelo conservando su rostro real

Foto de la prenda→ Foto de la persona (opcional)→ Análisis + prompts (IA)→ Revisión→ Imágenes (FLUX)
Avisos: la IA puede cometer errores al identificar la prenda, al describir el outfit o al extraer rasgos y medidas de la persona; revisa siempre el resultado antes de usarlo profesionalmente — esta herramienta no sustituye el criterio del diseñador, y las medidas extraídas de una foto son solo una estimación visual, nunca una medición real. Tu API key se guarda solo en este navegador (localStorage) y se envía únicamente al endpoint oficial del proveedor elegido; no se recomienda este mecanismo para secretos institucionales ni aplicaciones públicas de producción. Si subes la foto de una persona real, hazlo solo con su consentimiento: esa foto se envía al proveedor de IA elegido y a fal.ai para generar la imagen, y esta app no la sube ni la guarda en ningún servidor propio.
¿Cómo funciona GenOutFitFace?

GenOutFitFace es una aplicación de un solo archivo HTML pensada para diseñadores de moda: a partir de la fotografía de una prenda, usa IA para identificar sus características y proponer un outfit completo de prendas afines, genera una imagen de cada pieza con FLUX (fal.ai) y, opcionalmente, una foto de un/a modelo vistiendo el outfit completo que conserva el rostro real de una persona de referencia.

  1. Subes (o arrastras) la foto de una prenda.
  2. Opcionalmente, subes también la foto de una persona (de cuerpo completo o solo del rostro). Si subes una foto de cuerpo completo, la IA extraerá además sus proporciones y complexión aproximadas, siempre como estimación visual.
  3. Eliges cuántas piezas debe tener el outfit completo y si quieres además una imagen de un/a modelo vistiendo todo el conjunto.
  4. La IA (Claude, GPT o Gemini, a tu elección) analiza la(s) foto(s) y devuelve una descripción breve y un prompt en español, listo para FLUX, de cada pieza del outfit; si subiste foto de persona, también sus rasgos y, si procede, sus proporciones.
  5. Puedes revisar y editar cada prompt y cada característica extraída antes de continuar.
  6. Al pulsar "Continuar", GenOutFitFace genera con FLUX una imagen PNG de cada pieza. La foto del modelo se genera de dos formas distintas según el caso: si subiste una foto de persona, se genera con FLUX Kontext editando esa foto para vestir el outfit (conservando su rostro real); si no, se genera igual que el resto de piezas, solo a partir de texto.
  7. Puedes descargar cada imagen por separado o exportarlas todas juntas en un PDF.

Avisos frecuentes: error 401/403 → la clave no es válida o no tiene permisos. Error 429 → límite de uso alcanzado, espera e inténtalo de nuevo. Error 404 → el modelo no existe o no está disponible en tu cuenta (revisa también el identificador del modelo Kontext en APP_CONFIG.fal.kontext si falla solo la foto del modelo con referencia). "La respuesta no tiene el formato esperado" → GenOutFitFace reintenta automáticamente una vez; si persiste, prueba con otro modelo o fotos más claras.
