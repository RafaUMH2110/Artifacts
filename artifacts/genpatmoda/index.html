¿Cómo funciona GenPatModa?

GenPatModa es la versión para alumnos de GenPatMod: una aplicación de un solo archivo HTML que, a partir de la descripción libre de una prenda, genera con IA sus piezas de patrón de corte en SVG y las exporta como un PDF A4 listo para imprimir. No necesita instalación ni servidor: funciona con tu propia clave de API de Anthropic, OpenAI o Google.

  1. Describes la prenda con una idea inicial en lenguaje natural.
  2. La IA planifica qué piezas forman la prenda y sus medidas aproximadas (el "plan de piezas").
  3. Si la casilla "Mostrar y revisar el plan de piezas" está activada, la app se detiene para que revises o edites el plan antes de continuar.
  4. La IA genera el SVG de cada pieza por separado, a su tamaño real en centímetros.
  5. GenPatModa compone el PDF de forma determinista, sin IA: escala cada pieza a A4, la centra y añade una regla de control de 10 cm.
  6. La app muestra el resultado, lo guarda en el historial de este navegador y permite descargar el PDF completo y cada SVG por separado.

El resultado depende de:

  • La idea inicial: cuanto más detalle des, mejor será el patrón.
  • El proveedor y el modelo de IA seleccionados.
  • El número máximo de tokens de salida (el límite de cada modelo se muestra junto al campo).
  • Si editas el plan de piezas a mano antes de generar.

El PDF generado incluye una o dos páginas iniciales con el plan de piezas (si es muy largo, se trunca con un aviso), y una página A4 por pieza con su contorno a tamaño real —o reducido con la escala indicada si no cabe entera—, un título con prenda/pieza/medidas, y una regla de control de 10 cm reales: imprime siempre sin "ajustar a página" para que esa regla sea fiable.

Avisos frecuentes: "la respuesta de la IA se ha quedado corta" → sube el número máximo de tokens de salida y vuelve a generar. Error 401/403 → la clave no es válida o no tiene permisos. Error 429 → límite de uso alcanzado, espera e inténtalo de nuevo. Error 404 → el modelo no existe o no está disponible en tu cuenta. Si editas el plan a mano, mantén el formato ("Prenda: ..." y una lista numerada de piezas).

Prueba a cambiar solo una variable cada vez (proveedor, modelo, nivel de detalle de la idea) para observar su efecto sobre el resultado. El historial guarda cada generación con su idea, su plan y el PDF resultante, para que puedas recuperarlas o compararlas.
