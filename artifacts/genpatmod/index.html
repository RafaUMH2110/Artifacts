GenPatMod — Guía de utilización

GenPatMod es una aplicación web de un solo fichero que, a partir de la descripción libre de una prenda, genera con IA sus piezas de patrón de corte en SVG y las exporta como un PDF listo para imprimir en A4.

No necesita instalación ni servidor: se abre directamente en el navegador (o se aloja gratis en GitHub Pages) y funciona con tu propia clave de API de Anthropic, OpenAI o Google.

1. Requisitos

  • Un navegador moderno (Chrome, Edge, Firefox o Safari).
  • Una clave de API de al menos uno de estos proveedores:
    • Anthropic (Claude): console.anthropic.com/settings/keys
    • OpenAI (GPT): platform.openai.com/api-keys
    • Google (Gemini): aistudio.google.com/app/apikey
  • Una impresora (opcional) para imprimir el PDF a tamaño real.
🔒 La clave de API se guarda solo en tu navegador (localStorage) y se envía únicamente al endpoint oficial del proveedor elegido. GenPatMod no tiene servidor propio ni almacena nada en la nube.
🔤 El fichero incluye una marca UTF-8 (BOM) al principio para que los acentos y la "ñ" se vean bien aunque tu servidor envíe una cabecera de codificación incorrecta. No lo reabras y regrabes con un editor que pueda eliminarla.

2. Uso paso a paso

Paso 1 — Configura el proveedor de IA

En el bloque "1. Configuración del proveedor de IA": elige proveedor y modelo (o "Otro…" para escribir un identificador exacto), ajusta si quieres el número máximo de tokens de salida (el límite del modelo se muestra debajo del campo) y pega tu API key, pulsando "Guardar clave".

Paso 2 — Describe la prenda

Escribe la idea inicial en lenguaje natural, por ejemplo: "una camisa clásica de manga larga con cuello camisero, puños y botonadura delantera, talla M". Cuanto más detalle des, mejor será el resultado. Opcionalmente indica un nombre para el PDF y/o el .txt de prompts, y decide si quieres ver en pantalla el "prompt mejorado" con la casilla correspondiente. Pulsa Generar patrón.

Paso 3 — Revisa el plan antes de continuar

Al terminar la planificación, la app se detiene y muestra el "prompt mejorado" (si activaste la casilla del paso 2) esperando tu decisión: pulsa "▶️ Generar piezas con este plan" para continuar tal cual, o primero "✏️ Editar prompt mejorado" para corregirlo y luego "🔁 Generar con este prompt editado". Si desactivaste la casilla, la app genera las piezas automáticamente sin detenerse.

Paso 4 — Revisa el resultado

La app genera el SVG de cada pieza una por una y luego construye el PDF de forma determinista (sin IA): calcula el escalado a A4 midiendo el dibujo real de cada pieza, la centra, añade una regla de control y compone el documento final. Al terminar verás una tarjeta por pieza con su vista previa y un botón para descargar su SVG, la vista previa del PDF completo con su botón de descarga, y el contador de tokens y coste estimado de la sesión.

Paso 5 — Editar el plan y volver a generar (opcional)

Aunque ya se haya generado el PDF, puedes pulsar de nuevo "✏️ Editar prompt mejorado", corregir lo que necesites manteniendo el formato ("Prenda: ..." y una lista numerada de piezas) y pulsar "🔁 Generar con este prompt editado": la app regenera las piezas y el PDF directamente desde tu texto, sin repetir la llamada de planificación.

Paso 6 — Exportar los prompts usados

El botón "Exportar prompts (.txt)" descarga un fichero con la idea inicial, el plan de piezas y los prompts de sistema/usuario empleados en cada llamada — útil para documentar o repetir el proceso.

3. El PDF generado

  • 1 o 2 páginas iniciales con el mismo contenido que se muestra en pantalla en "Prompt mejorado" (si el plan es muy largo, se trunca con un aviso para no superar esas dos páginas).
  • Una página A4 por pieza, con la pieza a tamaño real (o reducida con su escala indicada si no cabe entera), un título con prenda/pieza/medidas, y una regla de control de 10 cm reales para comprobar que la impresión no ha reescalado el documento (debe imprimirse sin "ajustar a página").

4. Avisos y solución de problemas

  • "La respuesta de la IA se ha quedado corta por falta de tokens…": sube el "Nº máx. tokens de salida" (dentro del límite del modelo) y vuelve a generar.
  • Error 401/403: la API key no es válida o no tiene permisos para ese modelo.
  • Error 429: límite de uso alcanzado; espera unos segundos y reinténtalo.
  • Error 404: el identificador de modelo no existe o no está disponible en tu cuenta.
  • Tiempo de espera superado (60 s) o error de red: comprueba tu conexión y reinténtalo.
  • "No se ha podido interpretar el prompt editado": al editarlo a mano, no cambies la estructura general (línea "Prenda: ..." + lista numerada de piezas).

5. Advertencia

⚠️ La IA puede cometer errores en las medidas o en la forma de las piezas. Revisa siempre el patrón generado —y comprueba las medidas con la regla de control impresa— antes de cortar tela.
