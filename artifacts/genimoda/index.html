GenImOda

Generador de imágenes de moda mediante IA — versión para alumnos

Idea inicial→ IA (texto)→ Prompt optimizado→ FLUX→ Imagen
Aviso de seguridad: esta aplicación funciona directamente desde el navegador. Las API keys se almacenan localmente en este dispositivo y se envían únicamente al proveedor correspondiente para realizar las solicitudes. Almacenar una API key en localStorage es cómodo, pero no equivale a guardar un secreto en un servidor. No se recomienda este mecanismo para secretos institucionales ni para aplicaciones públicas de producción; para esos entornos se recomienda utilizar un backend o proxy seguro.
¿Cómo funciona GenImOda?
  1. El usuario introduce una idea inicial.
  2. Si la casilla «Mejorar el prompt con IA» está activada, el proveedor elegido (Claude, OpenAI o Gemini) analiza la idea y genera un prompt especializado en inglés; si está desactivada, se usa la idea inicial tal cual, sin llamar a ningún proveedor de texto.
  3. El prompt se envía a FLUX mediante fal.ai.
  4. FLUX genera la imagen.
  5. GenImOda muestra el resultado, lo guarda en el historial de este navegador y permite descargarlo en PNG.

La imagen resultante depende de:

  • La idea inicial.
  • Si se mejora el prompt: las instrucciones del sistema, el proveedor y modelo de IA elegidos (Anthropic/Claude, OpenAI/GPT o Google/Gemini) y el máximo de tokens (entre 1 y 8192 solo con Anthropic; con OpenAI y Gemini, cualquier entero positivo, sin tope forzado por la aplicación).
  • El modelo de generación de imagen.
  • El número de pasos de inferencia (1, 2, 3 o 4 en esta versión; 2 por defecto).

Prueba a cambiar solo una de estas variables cada vez para observar su efecto sobre el resultado. El historial guarda cada generación con su idea, su prompt y sus parámetros, para que puedas compararlas entre sí.

1. Configuración de las API keys

Cada clave solo se envía a su proveedor oficial (api.anthropic.com, api.openai.com, generativelanguage.googleapis.com o fal.run, según corresponda). La validez definitiva la confirma la respuesta del proveedor.

2. Modelos

Límite de longitud de la respuesta del modelo de texto (max_tokens). Entre 1 y 8192; por defecto 4096. Solo se usa si el prompt se mejora con IA.

3. Prompt

Si se desactiva, la IA no interviene: la idea inicial se envía tal cual a FLUX, sin usar la API del proveedor de texto ni las instrucciones del sistema.

5. Generar

Para activar el botón necesitas las dos API keys guardadas y una idea inicial.

La estimación consulta el conteo de tokens de ENTRADA (gratuito) del proveedor elegido, con la misma idea e instrucciones que se enviarían; no requiere la clave de fal.ai. Solo disponible si el proveedor elegido es Anthropic (Claude) o Google (Gemini) y la casilla «Mejorar el prompt con IA» está marcada (OpenAI no ofrece aquí un conteo de tokens de entrada equivalente, y sin mejora no hay ninguna llamada que estimar). Los tokens de SALIDA nunca se pueden conocer antes de generar, solo se puede mostrar el techo configurado.
