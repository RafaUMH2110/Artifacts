ConSultar

Mejora automáticamente tu consulta y obtén una respuesta completa, generada en dos pasos con la IA de Anthropic.

Configuración

Elige el modelo y ajusta los parámetros de la consulta.

Tu clave se usa únicamente en este navegador para conectar directamente con la API de Anthropic. No se guarda ni se envía a ningún otro servidor.
La llamada se realiza directamente desde tu navegador a la API de Anthropic. Por motivos de seguridad, esta forma de uso solo es recomendable para pruebas personales, nunca para una aplicación pública con usuarios distintos de ti.
La extensión se añade automáticamente según el formato elegido.

Consulta

Tu consulta se mejora primero automáticamente y después se envía como pregunta final.

Instrucciones de sistema para la respuesta final (puedes editarlas libremente).
Este texto se mejora automáticamente antes de enviarse como pregunta final.
Sube uno o más archivos (.txt, .md, .docx, .pdf) para que la IA los tenga en cuenta al generar la respuesta. Máximo 10 MB por archivo.
    Se guardará como .txt, con el «Rol del usuario» y la «Consulta» tal como los has escrito.

    Resultado

    La respuesta final aparecerá aquí, en formato Markdown.

    Todavía no se ha generado ninguna respuesta. Escribe tu consulta y pulsa «Consultar».

    Respuesta truncada: se ha interrumpido porque se ha alcanzado el límite de tokens disponible («Número de tokens» en la configuración). Auméntalo o simplifica la consulta para obtener una respuesta completa.
    Activa «Exportar resultado» en la configuración para habilitar la exportación.
